# 自适应三格角色设定提示词

## 任务

把用户本轮提供的角色文字、参考图、画幅和视觉风格，整理成一条完整中文角色设定生图提示词。提示词服务于角色身份、造型结构、角度识别和跨画面复用。

## 两种独立模式

依据输入状态选择一种模式：

### 有参考图模式

开头使用：

`基于所附参考图，生成一张[画幅]三格人物设定参考图。`

参考图锁定面部身份、发型发色、身材比例、服装造型、鞋履、配饰和固定辨识特征。提示词提取参考图中可见事实，并把姿势、构图、背景、光线和最终媒介写成新的设定。多张参考图按照用户指定职责分别提取特征，形成一位人物的一套统一造型。

### 无参考图模式

开头使用：

`生成一张[画幅]三格人物设定参考图。`

依据用户文字建立一位具体角色，写明年龄、性别、身份、身高、体型、人物比例、整体气质、脸型、五官、肤色、发型、妆容或胡须、固定辨识标记、服装、鞋履和配饰。缺少外观细节时补充可见设计值，并在整条提示词中保持统一。

## 剧本转译

角色设计先提取剧本中的六类信息，再转成可见外观：社会身份、戏剧职责、表面性格、内在矛盾、人物关系、变化方向。用一句话形成角色视觉命题，例如“在人前维持权威、内心害怕被时代淘汰的资深主管”。后续体型、五官、发型、色彩和服装围绕这句视觉命题共同服务。

转译顺序：剧本事实 → 视觉命题 → 身体轮廓 → 面部几何 → 发型习惯 → 专属色彩 → 服装证据 → 三个身份锚点。

最终提示词的身份段中明确写出“视觉命题：……”。视觉命题使用可拍摄的性格与冲突语言，连接剧本与外观，例如“用整齐的旧式穿着守住权威感，身体重量和疲惫眼神泄露出对新技术的戒备”。

## 体型与轮廓设计

体型同时写出身高、头身比、肩宽、胸腔、腰腹、骨盆、四肢比例、肌肉与脂肪分布、重心和站姿。优先形成远景可识别的轮廓，并写明衣物与身体的贴合关系。

体型描述采用“比例 + 结构 + 重心 + 轮廓”组合，例如：“约178厘米，五点八头身，肩宽胸厚、腰腹略松，颈部偏短，手臂结实，重心沉在脚跟，形成稳定的矩形轮廓”。

## 面部几何设计

五官使用可观察的结构语言：脸部长宽比例、额头与发际线、颧骨高度、下颌宽度、下巴形状、眉毛走向、眼裂与眼距、鼻梁与鼻翼、唇形与嘴角、年龄纹理、肤质和固定不对称特征。

每张脸提炼一个主结构和一个微小偏差，例如“宽下颌 + 左眉尾略高”“长脸窄颧骨 + 鼻梁右侧细小雀斑”，让角色在近景和剪影中都具备稳定识别度。

## 发型与生活方式

发型同时表达年龄、职业、时代、打理习惯和生活状态：发量、发际线、长度、质地、分缝、刘海、卷曲程度、白发、翘发、压痕、发饰和背面垂落方式。发型描述包含一个固定方向或固定细节，便于正面、背面和近景连续识别。

## 专属色彩系统

为角色确定主色、辅色、强调色、明度范围、饱和度范围和冷暖倾向。主色承担第一识别，辅色连接身份与环境，强调色形成视觉记忆点。多人同框时，角色之间的主色和明度形成清晰区分。

## 服装作为生活证据

服装同时呈现时代、地域、职业、阶层、穿衣习惯和使用历史。写明版型、松紧、面料、垂坠感、颜色、剪裁、磨损、褶皱、修补、功能性配件和一件反映性格的异常细节。服装细节按正面、背面、近景分工，形成可复用的结构证据。

## 身份锚点与群像区分

从完整设计中提炼三个最高优先级身份锚点，并在身份段、全身分格和特写分格中重复强化：一个身体轮廓锚点、一个面部或发型锚点、一个服装或色彩锚点。

当用户同时提供多个角色时，比较身高体型、脸型、发型轮廓、主色、服装层次和配饰类型，让角色在剪影、远景和近景中形成快速区分。

最终提示词的身份段中明确写出“身份锚点：轮廓锚点……；面部或发型锚点……；服装或色彩锚点……”。左格或下左格重复轮廓锚点，右格或上格重复面部/发型锚点，服装和色彩锚点在全身视图与特写中各出现一次。

## 角色与造型锁定

身份描述和造型描述作用于全部分格。人物身份、身体比例、发型、服装、配饰、材质、色彩、背景、照明和媒介保持连续一致。一张设定图呈现一位人物和一套造型。

服装结构按视图分工：正面全身承担正面服装、腰线、下装和鞋履核验；背面全身承担后脑、背部结构、后部服装、悬挂组件和鞋履核验；齐胸特写承担领口、肩部上缘、面部身份、发饰和耳饰核验。

## 画幅布局

三格使用干净纤细的分隔线，人物比例和分格尺度保持协调。

### 16:9 横屏

一个横向画面，左、中、右三个等分竖直分格。

左格：正面全身人台构图，肩部以下至鞋底完整入镜，颈部以平整清晰的水平切口收束，肩线以上保留连续背景空间。

中格：带头背面全身，人物从头顶至鞋底完整入镜，人物外侧配置细窄竖直身高比例尺。

右格：约30°至35°斜侧齐胸头部特写，脸部占据画面主体。

### 9:16 竖屏

一个竖向画面，上方为横向齐胸特写格，下方为左右两个并排全身格。

上格：约30°至35°斜侧齐胸头部特写，脸部占据画面主体。

下左格：带头正面全身，从头顶至鞋底完整入镜。

下右格：带头背面全身，从头顶至鞋底完整入镜，人物外侧配置细窄竖直身高比例尺。

全身格采用笔直站姿，双臂自然下垂，双手放松，重心均匀。比例尺从鞋底0 cm对齐至角色身高，每10 cm一条主刻度、每5 cm一条短刻度，标注一次 `HEIGHT [角色身高] CM`。

## 身份近景角度

特写摄影机位于角色自身左前方或右前方约30°至35°，人物肩线、胸口和头部向同一斜侧方向整体转动约30°至35°，头部保持水平，双眼视线回到镜头附近。远侧眼睛清楚可见，画面同时呈现近侧脸轮廓、鼻梁侧向线条、近远两侧颧骨转折、下颌线、耳部或耳侧发际线。

特写重复点名眉眼、睫毛、瞳孔或虹膜、鼻唇结构、皮肤或表面、发丝、发饰、耳饰、颈饰和固定身份标记。优先选择身份信息更丰富的一侧；两侧信息相同时采用角色自身左前方。

## 背景与照明

全部分格使用平坦均匀的18%中灰无缝背景，单一色值，平滑连续。采用均匀正面柔光，四周补光一致，画面保持清晰的材质阅读和稳定的明暗关系，背景与人物接触区域呈现干净平整的摄影棚效果。

## 媒介与风格

根据用户指定选择一种媒介与视觉风格，并将其质感写在提示词结尾：

当用户指定“高精度3D半写实国漫风格”、精致BJD人偶感、3D国漫少年/偶像或语义相近的风格时，完整读取并应用 [references/high-precision-3d-semi-realistic-guoman.md](references/high-precision-3d-semi-realistic-guoman.md)。该参考只补充角色建模、材质、发丝、服装、灯光与负面约束，不改变本 Skill 的三格布局、背景、比例尺、特写角度、提示词组织顺序和输出格式。

- 真人摄影写实：完整读取并应用 [references/photorealistic-skin-control.md](references/photorealistic-skin-control.md)，用分区纹理、局部高光、质感基调、轻微不完美和光线关系控制真人皮肤；同时保持真实相机成像、根根分明的发丝、清晰织物纹理和克制胶片颗粒。该参考不改变本 Skill 的布局与输出格式。
- 二维动画、动漫、韩漫、漫画：线条粗细、轮廓控制、人物比例、五官简化、平涂或赛璐璐上色、阴影层级、发丝分组和布料纹理。
- 三维动画或CG：统一角色模型、拓扑比例、毛发系统、皮肤或表面材质、布料材质、纹理精度和渲染方式。
- 定格、黏土、布偶、纸艺：材料触感、接缝、纤维、手工微瑕和逐格动画质感。
- 水墨、水彩、版画：笔触、纸张或画布质地、颜色边界和层次。

## 提示词组织顺序

开头句 → 视觉命题 → 身份描述 → 体型轮廓 → 面部几何 → 发型习惯 → 专属色彩 → 造型描述 → 身份锚点 → 对应画幅的三格布局 → 特写角度与身份细节 → 背景与照明 → 媒介和视觉风格。

画面中的文字集中于身高比例尺，内容为刻度数值与一次 `HEIGHT [角色身高] CM`。整体画面保持角色设定图的干净、准确、可复用状态。

## 版本选择

三格版本适合常规角色身份与造型确认。五视图版本适合复杂服装结构、机械组件、多角度视频资产和长期复用需求；用户提出五视图时，沿用同一身份锁定、材质、背景、照明和一致性原则，扩展为正面、背面、左侧、右侧、特写或顶部/底部等用户指定视图。

## 输出

只输出一条完整中文角色设定生图提示词，内容直接面向生图模型。
