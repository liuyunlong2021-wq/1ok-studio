# 真人摄影写实皮肤控制参考

## 适用范围

选择“真人摄影写实”媒介，或用户要求实拍人像、生活写真、杂志人像、真实闪光抓拍、CCD快照、自然皮肤质感时使用。本参考只负责真人皮肤及其受光关系，不改变 `SKILL.md` 的画幅、三格布局、分格职责、背景、比例尺、特写角度、提示词组织顺序与单条提示词输出要求。

用户提供的年龄、肤色、肤质、妆容、职业、生活状态和明确瑕疵优先。不要默认所有人物都年轻、白皙、无痘、无皱或精致妆容；儿童、老人、长期户外工作者和不同肤色人物应有符合身份的纹理尺度、色素变化与皮脂状态。

## 核心原则

不要只写“真实皮肤”“真实皮肤纹理”“超真实皮肤”或“8K毛孔”。这些大词容易让模型同时增加毛孔、磨皮、提亮和均匀水光，形成有纹理的塑料面具。

把皮肤拆成五个可见控制点，并让它们服从同一套光线：

1. 纹理：指定不同区域的毛孔、细小面部绒毛、浅纹与轻微凹凸，不把同一种毛孔均匀铺满全脸。
2. 高光位置：指定哪些区域可出现皮脂或受光高光、哪些区域保持更哑；高光应有边界，不连续覆盖全脸。
3. 质感基调：先确定自然半哑光、克制缎光或用户要求的其他基调，再配置局部高光；避免同时要求“全脸水光”和“半哑光”。
4. 轻微不完美：按人物选择一至两项自然泛红、小痣、浅纹、细微肤色差异或轻微左右不对称，不把全部瑕疵机械叠加。
5. 光线：写清主要受光方向、亮部边界、暗部与阴影过渡，让皮肤高光与面部体积、环境照明属于同一套光。

真实感来自区域差异，不来自细节总量。鼻翼毛孔、眼下浅纹、额头反光、脸颊半哑光和下颌暗部应呈现不同状态。全脸同亮、同哑、同毛孔密度或同一肤色都会削弱真实感。

## 默认组合：自然半哑光

日常写真、杂志感、生活人像和未指定特殊光效的真人角色设定默认使用这一组合：

`自然半哑光皮肤，保留符合年龄与身份的真实毛孔、细小面部绒毛、轻微肤色变化和自然凹凸，不过度平滑。T区即额头、鼻梁和鼻尖仅有克制的轻微皮脂高光，脸颊、下颌和眼周保持更哑的质感，高光分散且有边界，不连成一片。鼻翼可见细微毛孔，眼下保留极浅自然纹理，允许一至两项符合人物的自然泛红、小痣、细微色差或轻微不对称，皮肤保持真实体积和未过度精修的实拍质感。`

根据肤色调整高光强度、色素变化和泛红的可见程度，不把“白皙”当作真实皮肤的默认条件。深肤色同样保留局部高光边界、区域纹理差异与自然色素变化，避免用灰白提亮制造假面感。

## 条件分支：直闪或机顶闪光

仅当用户明确要求直闪、机顶闪光、CCD快照或强闪抓拍时使用。闪光可以强，但不同面部区域不能被打成同一种亮度：

`真实半哑光皮肤，保留符合人物的毛孔与细小绒毛。机顶小直闪主要提亮面部关键受光区域，高光集中在T区与朝向闪光的局部受光面，脸颊和下颌仍保留明暗层次，不出现全脸连续亮膜。皮肤高光克制、有边界，暗部保留自然过渡，面部与颈部、耳部和其他裸露皮肤共享同一闪光方向，整体呈现真实闪光抓拍而非棚拍磨皮效果。`

应用到角色设定图时，仍需保证面部身份、服装结构和各分格清晰可核验；不要为了模拟闪光而让暗部死黑或高光过曝。

## 条件分支：微瑕疵降 AI 感

用户要求未精修、原生、生活化或降低 AI 味，或默认半哑光仍显得过度完美时，选一至两项与角色相符的轻微不完美：

`真实人类皮肤质感，以半哑光为主，鼻翼与近侧脸颊保留清晰但自然的毛孔和细小面部绒毛，T区有轻微自然皮脂高光，眼下有极淡纹理；加入[一至两项：轻微自然泛红／一颗位置固定的小痣／局部浅淡色素差异／细浅表情纹／轻微左右不对称]，皮肤有真实体积与轻微不完美，像未过度精修的实拍照片。`

不要同时堆入雀斑、痘印、黑眼圈、粗大毛孔、泛红、皱纹和色斑。轻微不完美用于打破绝对均匀与完美对称，不用于故意做脏、做旧或改变人物年龄。固定痣、雀斑或疤痕若成为身份特征，应纳入身份锚点并在所有带头分格保持位置一致。

## 分格与全身一致性

- 皮肤细节重点写入带头全身格和齐胸特写格；无头人台格只呈现颈部以下可见皮肤，不生成脸部信息。
- 同一人物的脸、耳、颈、手臂和双手共享肤色、皮脂状态、受光方向与总体质感，但不同身体部位的纹理尺度应自然，不把面部毛孔复制到全身。
- 齐胸特写负责核验鼻翼毛孔、眼下浅纹、细小绒毛、高光边界、固定小痣或色差；全身格只需保持可见的一致肤色、体积与受光，不强行显示微观毛孔。
- 同一组图保持同一皮肤基调与高光逻辑。除非用户明确设计状态变化，不要一格半哑光、一格全脸水光、另一格完全死哑。
- 妆容与皮肤分开写：粉底、腮红、修容和高光产品不得抹掉人物应保留的区域纹理，也不得把化妆高光误写成全脸皮脂。

## 光线与主 Skill 的协调

默认沿用主 Skill 的均匀正面柔光与四周补光，同时保留轻微方向性和自然明暗过渡，让额头、鼻梁、鼻尖等朝向光源的区域出现克制高光，脸颊、眼周与下颌维持更哑或更暗的层次。均匀补光用于结构核验，不等于把全脸打成同一亮度。

用户明确要求直闪时才调用直闪分支；背景、布局、比例尺和分格职责仍沿用主 Skill。用户指定其他明确光线时，根据真实受光面重算高光位置，不机械套用“T区一定亮、脸颊一定哑”。

## 负面约束的追加条件

正面描述先负责建立皮肤。如果用户要求强负面约束，或已有结果表现出特定失败，再追加对应的最小负面词；不要默认塞入整组：

- 全脸油膜或连续湿亮：`避免全脸连续湿亮、全脸油膜、统一发光皮肤，高光不得无边界连成一片。`
- 蜡像、陶瓷或塑料感：`避免塑料皮肤、陶瓷皮肤、蜡像感、塑料高光。`
- 过度磨皮或假光滑：`避免过度磨皮、过度平滑、失去自然凹凸、闪光造成的假光滑感。`
- 全脸同种纹理：`避免全脸统一毛孔、砂纸感、过度锐化的皮肤纹理。`
- 光线打平：`避免全脸被均匀提亮、无明确受光面、无暗部层次、面部与环境光线脱节。`
- 假完美：`避免绝对无瑕、完美对称假脸、肤色完全均一。`

负面词只用于收住已出现或高概率出现的翻车结果，不能代替正面描述。不要用“不要油光”否定所有高光；这会把皮肤压成死哑。应保留局部受光和克制皮脂高光。

## 诊断与改写顺序

已有出图显假时，按以下顺序改提示词：

1. 先看高光：若额头、鼻梁、鼻尖、脸颊同时连续发亮，先收窄到真实受光面并建立高光边界。
2. 再看光线：若面部没有明确亮面、暗部和过渡，补主要受光方向、阴影层次及面部与环境的一致关系。
3. 最后看纹理：区分“纹理不足”与“全脸同纹理”。前者补局部毛孔、绒毛或浅纹；后者减少均匀纹理并建立区域差异。
4. 若仍显完美假脸，再选择一至两项轻微不完美；不要先用大量瑕疵掩盖错误高光。

## 最小可复用结构

生成提示词时至少写清：

`区域化纹理 + 局部高光位置 + 质感基调 + 一至两项轻微不完美 + 合理光线`

不同图像模型对“半哑光”、局部高光和负面约束的响应不同；若用户指定模型或提供试生成结果，应按实际结果调整强度，但不改变上述五项之间的关系。
