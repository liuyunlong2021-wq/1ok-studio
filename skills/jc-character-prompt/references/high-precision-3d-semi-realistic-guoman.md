## 风格核心

把风格写成一套互相协调的可见特征，而不是只附加一个风格标签：

- 总体成像：高精度3D半写实国漫角色设定图，精致BJD人偶感，介于写实人体结构与理想化CG角色之间，轮廓准确，商业级角色建模与材质精度。
- 人体比例：尊重用户设定；偏偶像或时装方向时，可采用舒展肩颈、清楚腰线、修长四肢与协调头身比。纤细不等于病态，修长不等于大头短腿。
- 面部建模：强化清晰的面部骨骼结构、立体眼睑、鼻梁、颧骨转折与下颌线；五官精致但保留角色的性别、年龄和身份特征，避免模板化网红脸。
- 肤质：干净、细腻、哑光的CG皮肤材质，保留柔和体积和适度次表面散射，主动降低真人毛孔、油光、胡茬和粗糙皮纹；不要写成无体积的塑料皮。
- 眼神与妆容：瞳孔与虹膜清晰，眼神明亮有聚焦；妆容服从人物身份，偶像型角色可用清淡精修妆和自然柔和唇色，不默认女性化浓妆。
- 发型与毛发：写明高颅顶或贴颅顶、长度、分缝、卷曲和固定方向；使用高精度CG毛发系统，发束有层次，关键发丝根根分明，带克制通透的发丝光，避免整块塑料假发。
- 服装材质：版型、层次、拼色、口袋、滚边、抽绳、徽章或印花必须落到可见结构；区分针织、棉质、机能织物、金属与做旧皮革等材质，宽松造型仍需保持肩线、腰线和垂坠逻辑。
- 配饰控制：选择少量能证明身份或主题的配饰，写清佩戴位置、颜色、材质和结构；丰富但克制，不用无意义首饰堆砌画面。
- 渲染与灯光：统一角色模型、拓扑比例、皮肤着色、毛发系统、布料材质和纹理精度；均匀正面柔光负责结构核验，可加入暖白侧逆轮廓光、克制体积光、CG发丝光与肩颈轮廓光，保持设定图清楚、稳定、可复用。
- 精度词：电影级商业角色影棚布光，8K高清观感，边缘干净，材质精致。精度词用于强化细节，不得制造浅景深虚化而妨碍各分格的结构核验。

## 组合方法

先确定角色事实，再从下列槽位选择与人物相符的内容，写入 `SKILL.md` 的既定组织顺序：

1. 风格基底：`高精度3D半写实国漫角色设定图，精致BJD人偶感，[角色核心气质]。`
2. 身体结构：写用户身高与头身比，再写肩颈、腰腹、四肢、重心和轮廓；不得机械复制“220厘米、九头身”。
3. CG面部：把脸型和五官事实连接到面部骨骼、眼睑、鼻颧和下颌建模；依据身份决定精修程度。
4. 表面材质：使用细腻哑光CG肤质、适度次表面散射和低毛孔感；非人角色则改写为对应表面材质。
5. 高精度毛发：具体发型事实 + 发束层次 + 毛发系统 + 发丝光。
6. 造型主题：用“廓形 + 风格来源 + 主辅强调色 + 单品结构 + 材质”建立服装，不照抄示例商品清单。
7. 统一渲染：把统一模型、材质精度和适合结构核验的影棚灯光放在结尾风格段。
8. 负面约束：只保留与当前人物和媒介相关的失败项，不要否定用户明确要求。

三个身份锚点仍按主 Skill 生成。此风格下可优先从“远景身体轮廓”“稳定的脸型或发型方向”“服装主色与标志性结构”各选一个，分别在身份段与对应分格复现。

## 与现有三格格式的映射

经过验证的原始范例使用过“左侧大幅正脸特写，右侧正面、侧面、背面全身”和纯白背景。不要复制这些版式条件，改写为主 Skill 的固定格式：

- 16:9：左格无头正面全身人台，中格带头背面全身，右格30°至35°斜侧齐胸头部特写。
- 9:16：上格30°至35°斜侧齐胸头部特写，下左带头正面全身，下右带头背面全身。
- 背景：沿用平坦均匀的18%中灰无缝背景，不改为原范例的纯白背景。
- 光学语言：可吸收商业人像影棚质感，但不得用 `85MM、F/2.0浅景深` 造成全身格、背面结构、鞋履或比例尺失焦。
- 视图数量：不得因为范例包含正、侧、背视图而把三格擅自扩为四格；用户明确提出五视图时才使用主 Skill 的五视图版本规则。
