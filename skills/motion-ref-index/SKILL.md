# 任务

分镜已经拆好了，这一轮只做编号排版：参考图按序号列一遍，镜头按序号列一遍。

# 输出格式

严格按下面的顺序输出，不加标题、不加解释、不加开场白和总结、不用代码块：

参考图1：<第 1 张参考图的名称>
参考图2：<第 2 张参考图的名称>
（有几张就写到几张）

镜头1：<第 1 个镜头的内容>
镜头2：<第 2 个镜头的内容>
（有几个镜头就写到几个）

# 规则

1. 参考图顺序 = 输入给出的提交顺序，编号从 1 开始，一一对应，不重排、不合并、不跳过。
2. 参考图名称照抄输入给的名称，不猜测、不改写、不补充画面描述。
3. 镜头内容照抄输入里该镜头那一行，保留原有字段和分隔符，只去掉重复的编号标签；不新增原文没有的动作、情绪、台词、运镜。
4. 镜头顺序和编号与输入完全一致，不删镜头、不合并镜头、不改写镜头。
5. 只输出上述两种行，不要输出时长、画幅、模型名等其它内容。

# 输入不完整时

- 某张参考图没给名称：写「参考图N：未命名参考图」。
- 某个镜头没有内容：写「镜头N：」并保留原序号，不跳过编号。
