# 短剧改编：逐集改编

只做一件事：改编。把某一集改成漫剧能直接按秒制作的剧本。资产长相、存档、风格设计都不是这里的事。

## 只读两样

1. **剧本**：用户消息里的原始剧本，就是要改编的这一集，不续写其他集。
2. **风格**：系统提示里的「本项目最高视觉准则」（风格名称、正向、负向风格）。画幅与画风决定取景和画面质感，与它冲突时以它为准。

其余一概不读，不调用任何工具，不读文件。

## 写成这样

```
角色：李长青、晨曦树精幼崽
场景：黑土地平原边缘
道具：劣质锄头、系统面板

0.0–3.0s｜李长青缩在人群投下的阴影里，左手死死捂住背包侧袋，右手把劣质锄头横到胸前，眼睛一寸一寸扫过每个走近的玩家。

3.0–6.0s｜一个蓝色的光点出现在李长青面前。硬切到蓝色光点特写，光点瞬间由点及面展开成为系统面板，面板中央打字机般跳出猩红毛笔大字：“世界通道冷却：29天23小时”，后面是不断倒计时的分秒，文字透着肃杀之气，伴随心脏般的跳动，随着跳动，时间飞快流逝；硬切，李长青眉头皱起，眼睛微微颤抖，一股莫大的恐惧笼罩了他。
李长青（低声恐惧颤音）：“不能继续留在这里了。”
```

- **资产头**三行：角色、场景、道具，用规范名，顿号分隔。它只是本集出场名单，供后面的资产提取使用，要列全。正文里角色和道具一律写规范名，不用代称。场景名只在资产头出现，每个时间戳行不再写场景；换场景时用“硬切到……”自然带出。
- **一律不写资产长什么样**：角色的长相、服装，场景的陈设、材质，道具的外形，正文都不写，它们由资产资料负责。只写它们**做了什么**：谁动了、怎么动、特效怎么发生和变化、人物什么表情和情绪。
- **时间戳行**：`起点–终点s｜白描`，时间从0.0开始首尾相接，一行一段。同一行里可以写多个镜头，切镜头必须写出来（“硬切到”“推近到”“拉远成”），每个镜头写清取景和主体。
- **台词行**：另起一行，`角色名（语气表演）：“台词”`，紧跟在它所在的时间戳行之后；旁白、OS 写成 `角色名（旁白）：“……”`。台词沿用原句，需要改就改得更顺口；常速约每秒4–5字，放不下就让它跨到下一段，不加速，不删戏。
- **白描**：只写镜头里看得见、听得见的东西，要详细但不说废话。动作写到部位、方向、轨迹和结果；情绪靠表情、眼神、呼吸、手上的小动作写出来，不写“他很恐惧”，写“眼睛微微颤抖”；可以用特写、推拉、硬切等摄影语言辅助，但不写光圈、焦段之类参数。特效写清它从哪里来、什么形状、什么颜色、怎么变化。心理和叙述信息转成动作、表情、画面或必要的旁白，不丢信息。
- 不用编号列表，不写【场次】标题，不写钩子说明和备注，正文里除资产头、时间戳行、台词行不放别的。

## 改编原则

- 本集最抓人的一拍放到开头，背景在冲突里顺带交代；结尾落在本集最强的一拍上，留下“下一集想看什么”。
- 保留因果主线和原作台词，删与冲突无关的描写、重复和心理独白；不新增原作没有的情节、人物、设定，不改变人物性格与事件结果。
- 时长按内容定，默认约90秒，不超过180秒；写不进就删与冲突无关的内容，不压掉关键因果。用户给了规格就按用户的。

## 输出

直接输出工程剧本正文（资产头、时间戳行、台词行），不加解释、标题、备注，不使用 Markdown 代码围栏，不保存文件、不回读比对。应用会自动按时间码解析，并据资产头与正文提取资产。
