# 任务

把剧本文本拆成按时间连续的独立镜头。每个镜头写一段**镜头融入描述**：机位在哪、怎么运动、景别怎么走、拍的是什么、台词怎么念出来，合成一句连贯的话，不要拆成"画面/运镜/台词"几段分列。台词原文照抄，不改字、不缩写、不翻译。

# 镜头融入描述

一句话按这个顺序串起来：

**镜头在〈人物〉的〈方位：左侧／右侧／正前方／斜后方／背后〉，〈运动：缓缓推近／缓拉／横移跟拍／环绕／升起／下降／手持轻微晃动／固定〉，〈起幅景别〉到〈落幅景别〉拍摄〈人物＋部位或物件〉。〈声音来源＋人物＋情绪＋声音状态〉说：〈台词原文〉。**

- 景别只写一个时，就是全程不变；从近到远或从远到近，写成"近景到特写"。
- 没有台词的镜头，省略"说："那半句，改成写这一镜听得见的声音或动作收尾。
- 台词的念法写在"说"字前面：谁在说、什么情绪、用什么声音状态（压着嗓子／咬着牙／气音／发抖／笑着／喊）。情绪靠声音和动作体现，不靠形容词堆砌。
- 画外音、延续上一镜、隔壁房间传来，都要在说话人前标出来，例如"画外音延续张飞继续愤怒的压着嗓子说"。

# 第一个镜头：整集剧情 + 声音 + 音乐

**只有第 1 个镜头**在镜头描述之前加一段总起，写整个这一集，之后各镜都不再重复。格式固定：

**生成一段〈画幅〉电影片段，讲述〈整集一句话剧情〉。〈先是一声……的声音，环境中伴随着……〉音乐以〈主奏乐器〉为主奏乐器，加入〈配器〉，整体情绪〈情绪词〉。**

- 画幅写项目画幅，默认 `16:9`；竖屏项目写 `9:16`。
- 声音句：先写最先听到的那一下（"先是一声武器震动的声音"），再写持续的环境底噪（"环境中伴随着持续的鸟鸣声"）。
- 音乐句：主奏乐器在前，配器按"pad 铺底、弦乐组、合成器 lead、电贝斯、打击乐"这样的顺序列，收在整体情绪上。
- 整集剧情一句话，写清谁被怎样、情绪是什么，不写结局，不剧透后续集。

第 1 个镜头的形式是：`总起段` + `镜头融入描述`，仍写在同一个 `visual_description` 里。

# 拆解规则

1. **一帧一动作**：一行里有多件事就拆成多个镜头，每个镜头只推进一件事。
2. **一帧一说话人**：多人对话必须拆开，每镜只有一个 `speaker`。台词原文照抄，一字不改。
3. **实体名严格照抄**剧本里已提取的角色名、场景名、道具名，不新造、不改称呼。
4. **景别枚举**：大特写｜特写｜近景｜中景｜全景｜远景｜大远景。
5. **角度枚举**：平视｜俯视｜仰视｜鸟瞰｜蚁视｜过肩｜荷兰角｜主观视角。
6. **时长**：按动作复杂度取整数秒，范围 3–10。静态 3–4 秒，常规动作 5–6 秒，复杂或强情绪 7–10 秒。
7. **可见性**：`character_ref_names` 只列画面里看得见的角色；只在画外说话的不列入。

# 剧本格式

- 场景标题行：`1-1 地点名称 [时间] [内/外]`
- 人物行：`人物：角色名1，角色名2`
- 动作描述：以 `△` 开头
- 对白：`角色名（情绪）：对话内容`；`角色名 (V.O.)：` 表示画外音

# 输出格式

只输出 JSON 对象 `{"frames": [...]}`，不要 Markdown 代码块，不要解释。每帧字段：

| 字段 | 内容 |
| --- | --- |
| `scene_ref_name` | 场景名 |
| `character_ref_names` | 画面中可见的角色名数组 |
| `prop_ref_names` | 画面中可见的道具名数组 |
| `action_summary` | 一句话概括这镜发生什么（动作＋物理事件＋神态），供列表用，不写机位 |
| `visual_description` | 镜头融入描述；第 1 镜为总起段＋镜头描述 |
| `shot_size` | 落幅景别，取枚举值 |
| `camera_angle` | 取枚举值 |
| `camera_movement` | 运动方式，如"缓缓推近" |
| `dialogue` | 台词原文，无对白为 `null` |
| `speaker` | 说话人，无对白为 `null` |
| `duration` | 整数秒 |

# 自检

- 每个镜头的 `visual_description` 都是一整段连贯的话，读出来能听出机位、运动、景别、拍谁、台词怎么念。
- 只有第 1 镜有总起段，且总起段里剧情、声音、音乐三样齐全。
- 台词与剧本原文逐字一致；`dialogue` 与 `speaker` 同有同无。
- 输出的字段名与上表完全一致，没有多余字段——多余的字段会被丢弃。

> `{entities_str}` 和 `{text}` 两个占位符必须原样保留：调用方靠它们代入实体清单和剧本正文，改掉就收不到剧本。
