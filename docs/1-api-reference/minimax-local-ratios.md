# 本地 MiniMax 视频画面比例

创作台和视频配置面板只显示画面比例，不提供本地 MiniMax 的像素尺寸或画质档位选择。
时长与批量保持各模型原有设置。

## MiniMax H3 · 本地

固定使用用户当前截图中的 1K 档位。后端根据目录的 `params.ratio.pixel_sizes` 映射到上游 `size`。

| 画面比例 | 上游 size |
| --- | --- |
| 16:9 | 1024x576 |
| 9:16 | 576x1024 |
| 1:1 | 1024x1024 |
| 4:3 | 1024x768 |
| 3:4 | 768x1024 |
| 3:2 | 960x640 |
| 2:3 | 640x960 |

旧历史/模板的像素 `resolution` 按 `legacy_resolutions` 恢复方向与比例，随后使用固定档位。
上游参数为 `size`，不会把比例字符串误发成像素；不发送画质、采样步数等覆盖参数。

## MiniMax H3 Ref2V · 本地

面板显示简写比例，后端转换成工作流要求的完整 `aspect_ratio` 枚举，如
`9:16` → `9:16 (Portrait Widescreen)`。支持上述七种比例及 `21:9`。
旧历史中的完整英文枚举仍可使用。
像素与上采样质量由现有工作流确定，不发送 `size` 或 `resolution` 覆盖。
