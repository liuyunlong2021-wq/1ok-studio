# H3 提示词增强交付说明

已在 One OK Studio 中新增内置 Skill「MiniMax H3 提示词增强」。提示词编辑器与工作区“动作”步骤共用同一个 Responses 任务服务。

## 使用

- **提示词编辑器**：在“AI 创作与修改”的 Skill 下拉框选择该 Skill。填写正文或本次要求，设置 4–15 秒整数时长和画幅，点击“增强提示词”。有正文时增强正文或选区；无正文时按本次要求创作。选定风格会作为文字要求传入。
- **图片用途**：默认将右侧图片按当前顺序作为参考图；也可选择首帧、尾帧或首尾帧。首帧/尾帧各需一张图，首尾帧需要两张图，第一张为首帧、第二张为尾帧，画幅由帧图决定。与参考图模式互斥。
- **动作步骤**：选择连续镜头，在“提示词配置”选择该 Skill，再点击“增强提示词”。时长取所选镜头时长之和，画幅取项目分镜画幅。已有提示词直接增强；空白时先本地拼装镜头与参考图说明。已选参考图按顺序上传和绑定。
- **采用结果**：结果先预览，采用前校验发送时的原文与上下文。输入或镜头已经变化时保留结果供复制，不覆盖新内容。提示词编辑器沿用原有文档历史和撤销；动作页面提供“恢复增强前提示词”。
- **Skill 管理**：说明只读，可隐藏或恢复显示。恢复显示同时恢复两个入口的可选项。

创作台继续使用已经准备好的提示词生成媒体，本次接入不在创作台增加增强选项。

## 接入与任务恢复

- 网关固定为应用现有韭菜盒子通道，复用设置中的 `JIUCAIHEZI_API_KEY`。
- 共享入口为 `POST /prompt-enhancements`、`GET /prompt-enhancements/{request_id}`；调用 `MiniMax-H3-Context-IR` 的 `/v1/responses`。
- 请求在浏览器端先保存 UUID，后端按 UUID 幂等创建任务。记录与源快照落在 `output/prompt_enhancements/`；不写入 Key。
- 浏览器关闭页面停止查询，重新进入相应文档/项目时继续查询原任务。得到上游顶层 `resp_...` ID 后先保存，再检查任务输出。
- GET 查询可恢复；遇到 429 拉长间隔。等待十分钟后暂停，可点击“继续查询”。
- POST 超时、5xx、无有效响应 ID 或提交期间进程重启，保留“提交状态待确认”，禁止自动重提。结束等待不会取消上游任务。
- 素材读取/上传失败在提交增强任务前结束；不降级为纯文本。不使用 `usage` 判断成功或费用。
- 只有 `completed` 且 `output_text` 非空才可采用；失败、空输出、原文变化均不自动写入正文或提交视频。

## 素材约束

沿用编辑器的 PNG/JPEG/WebP 素材读取和应用目录校验，单张不超过 10MB，总量不超过 30MB。H3 校验宽高各 256–5760 像素、宽高比 0.4–2.5，参考图最多九张。编辑器保持现有八张上限，动作页面保持视频模型自身素材上限；超过九张时不能执行本 Skill。

本机素材通过应用现有韭菜盒子临时上传接口得到公网 URL；增强请求不传本机路径或大文件 Base64。图片编号与输入顺序固定。当前两个页面的素材入口为图片，本次覆盖文本和图片上下文。
