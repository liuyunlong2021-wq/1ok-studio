# Fk Seedance 接入与安装记录

## 入口与范围

新增 7 款当前韭菜盒子账号可见的 Fk Seedance：特价 30 图、真人通道、长期特惠 30 秒、XZ 9 图、XN1、XN2、官方通道。入口为工作区“动作”的模型卡片、创作台的视频模型选择，以及项目/系列/全局模型设置。默认模型保持原值。

文档中的 Fk MiniMax H3 768p 已登记，但认证 `GET /v1/models` 未返回该 ID，因此隐藏入口，账号开通后再显示。模型价格说明依据 2026-10-06 提供的合同；实际费用以平台账单为准。

提示词编辑器中目标时长和画幅控件已统一为 40px 高、两列等宽、边界对齐；macOS 原生下拉框改用明确高度与下拉图标，消除原生外观造成的高度差。

## 请求与素材

- 复用韭菜盒子 API Key 和 `/v1/videos`；不使用 Fk 上游凭证、接口或任务号。
- 每个模型独立声明时长、分辨率、画幅、图片/视频/音频上限及明确公布的提示词长度。
- Fk 使用 `imageUrls`、`videoUrls`、`audioUrls`，不套用旧通道 9 图截取规则。
- 工作区“动作”沿用现有参考图绑定；创作台 R2V 参考区可混合上传/选取所选模型允许的视频和音频，分别校验数量。可复用生成结果作为混合参考。
- 本地素材通过已有临时上传入口获得公网 URL。继续沿用应用现有上传大小限制，不传本机路径或 data/file/blob URL。
- 工作区和创作台保存 NewAPI 创建响应的 `id` 后再轮询；创建超时不自动重发。Fk 状态为 unknown 时保留 ID 并报错。
- 通过带鉴权的 content 接口下载；拒绝 JSON/HTML 错误页和空响应，不回退到自行拼接的 Fk 上游成片地址。
- 修复目录兼容导出丢失 runtime 元数据的问题，避免按模型名猜测通道合同。
