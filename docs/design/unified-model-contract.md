# 统一产品模型合同

## 目标

产品中的文本、图片、视频、音频模型由同一份模型目录提供。设置页、工作区、创作台和项目配置不再各自维护模型名单。

## 模型目录

目录源文件位于 `config/model_catalog/`，生成后同时供后端和前端读取。每个模型至少声明：

- `id`、`display_name`、`family`、`provider`
- `capabilities`：`text`、`image`、`video`、`audio` 对应的能力组
- `ui.selection_group`、可见页面、排序、推荐状态
- `status`、运行时网关和凭据来源

韭菜盒子文本模型固定纳入目录：`claude-fable-5-1`、`claude-sonnet-5`、`deepseek-v4-pro-0813`、`gemini-3.8-flash`、`gpt-5.6-sol`。

## 默认与覆盖

设置页只管理全局默认模型；工作区/创作台读取全局默认，并允许当前任务临时切换，临时切换不修改全局设置。项目或系列可以保存项目级覆盖。

解析优先级：

```text
任务临时选择 > 项目设置 > 系列设置 > 全局设置 > 系统默认
```

当前任务开始后锁定其模型，默认模型的后续修改只影响新任务。

## API 与安全

API URL 和 API Key 属于提供商配置，文本模型选择属于模型配置，两者分离。Key 只保存在后端环境配置中，不下发到前端；前端只接收目录和当前选择。

## 兼容策略

- 旧媒体默认字段和旧项目文件保持可读。
- 旧 `polish_model` 继续作为项目/系列文本模型覆盖字段；为空时走统一默认解析。
- 现有 `lumenx_default_model_settings` localStorage 继续读取，新增字段缺失时由目录默认补齐；服务端配置优先于缓存，缓存优先于目录默认。

## 验收

1. 设置页能选择并保存默认文本模型，五个韭菜盒子模型均来自目录。
2. 工作区文本任务默认使用设置页选择，当前任务可临时切换。
3. 旧图片、视频、音频模型和旧项目配置行为不变。
4. 目录生成、校验、前端类型检查和后端测试通过。
