# Motion 参考图驱动升级合同

状态：已确认，进入实施  
日期：2026-09-06

## 1. 目标

在不改变首帧驱动（I2V）和现有视频队列主结构的前提下，将第 5 步 Motion 的“角色驱动”升级为适配韭菜盒子 Seedance 2.5 的“参考图驱动”。一次任务使用连续多镜头、最多 9 张角色/场景/道具参考图和一个 Motion Skill，生成一条可编辑的视频提示词并提交 30 秒视频。

## 2. 不变项

- 首帧驱动的选择、上传和生成流程不变。
- 继续使用现有 `VideoTask`、视频后台任务、队列和结果预览。
- 项目设置中的视频模型、文本模型和画幅仍是唯一配置来源。
- 不新增 `VideoSegment` 数据表，不重做 Assembly 时间轴。

## 3. 用户流程

```text
参考图驱动
  -> 选择一段连续镜头
  -> 选择 1-9 张参考图（角色/场景/道具/上传）
  -> 选择或上传 Motion Skill
  -> 生成并人工编辑 1-12000 字视频提示词
  -> 使用 Seedance 2.5 固定生成 30 秒视频
  -> 在现有任务队列查看结果
```

## 4. 交互合同

### 4.1 模式

- “角色驱动（R2V）”统一显示为“参考图驱动”。
- 参考图驱动只接收图片，不显示角色视频槽或参考视频入口。
- 切换到参考图驱动时，使用项目设置中的 R2V 模型；默认仍遵循现有模型合同。

### 4.2 镜头选择

- 支持单镜头和连续多镜头。
- 第一次点击确定起点，第二次点击确定终点并选中中间全部镜头；再次点击重新选择。
- 显示镜头范围、镜头数量和分镜建议总时长。
- Seedance 2.5 固定输出 30 秒。建议总时长不是提交参数；与 30 秒不一致时只提示 Skill 将进行压缩或展开。
- 提交顺序始终使用 Storyboard 原始顺序。

### 4.3 参考图

- 参考图来源包括角色、场景、道具和本地上传。
- 最少 1 张，最多 9 张；前端阻止第 10 张，后端拒绝越界请求。
- UI 按选择顺序显示“参考图 1”至“参考图 9”；提交数组顺序必须一致。
- 允许删除和替换。首版不做拖拽排序，删除后可按需要重新选择。
- 上游 API 虽允许 30 张，本产品合同统一限制为 9 张。

### 4.4 Motion Skill

- 复用现有 Skill 的新增、上传、重命名、编辑和删除能力。
- Skill 增加 `kind`：`script` 或 `motion`；旧数据缺省为 `script`。
- Motion 只列出 `motion` Skill，剧本编辑器只列出 `script` Skill。
- 文本模型复用项目现有文本模型设置。

### 4.5 提示词

- “生成提示词”输入：所选镜头的结构化内容、参考图编号与资产说明、固定 30 秒、项目画幅和 Motion Skill。
- 输出只包含一条中文视频提示词，不包含解释或 Markdown 代码块。
- 结果必须可编辑并显示字数；允许 1-12000 字，越界不能提交视频。
- 用户手工编辑后的文本是最终提交文本，系统不得在提交时再次隐式改写。

## 5. 数据合同

现有 `VideoTask` 增加可选兼容字段：

```ts
source_frame_ids: string[]
skill_id?: string
skill_name?: string
```

- `frame_id` 保留并写入所选第一个镜头，兼容旧队列及旧数据。
- `source_frame_ids` 按 Storyboard 顺序保存全部所选镜头。
- `skill_id` 与 `skill_name` 是生成时快照，Skill 后续改名或删除不影响历史任务。
- 旧任务缺少这些字段时按单镜头任务展示。

视频提交合同：

```json
{
  "generation_mode": "r2v",
  "prompt": "1-12000 字",
  "reference_image_urls": ["1-9 张可访问图片"],
  "duration": 30,
  "ratio": "项目设置画幅",
  "source_frame_ids": ["连续镜头 ID"],
  "skill_id": "可选",
  "skill_name": "可选"
}
```

## 6. 后端校验

- 项目和所有 `source_frame_ids` 必须存在。
- `source_frame_ids` 不得重复，且必须在项目中连续。
- Seedance 2.5 参考图驱动必须包含 1-9 张参考图。
- 提示词去除首尾空白后必须为 1-12000 字。
- Seedance 2.5 的 `duration` 强制归一为 30，分辨率固定为 720p。
- 校验失败返回明确的 HTTP 400，不创建后台任务。

## 7. 验收标准

- 首帧驱动没有行为回归。
- 参考图驱动可以连续选择 10 个或 20 个镜头。
- 角色、场景和道具图片均可进入同一组参考图，且最多 9 张。
- Motion Skill 可上传、选择、重命名、编辑和删除，且不污染剧本 Skill 列表。
- 生成提示词包含全部所选镜头上下文并可手工编辑。
- 超过 12000 字、没有镜头、没有参考图或超过 9 张时无法创建任务，并显示原因。
- 成功任务保存全部镜头 ID、Skill 快照、参考图顺序和最终提示词。
- 刷新后任务仍能显示对应镜头范围。

## 8. 明确延后

- 不做独立视频段数据库。
- 不做自动拆分多个 30 秒任务。
- 不做参考图拖拽排序。
- 不改 Assembly 的剪辑逻辑；本期仅保证多镜头来源随任务保存并可识别。
